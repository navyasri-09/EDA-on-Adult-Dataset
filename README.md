# 📊 Adult Dataset Exploratory Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Adult dataset using Python. It focuses on data cleaning, statistical analysis, missing values, outlier detection, and visualization.

---

## 🚀 Features

* Data Cleaning & Preprocessing
* Missing Value Analysis
* Statistical Analysis
* Outlier Detection
* Data Filtering & Grouping
* Data Visualization
* Automated EDA

---

## 📊 Dataset Analysis

The project analyzes:

* Age
* Workclass
* Education
* Occupation
* Working Hours
* Income
* Other demographic attributes

## 🚀 How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn plotly scipy sweetviz ydata-profiling
```

Open `EDA_project1(1).ipynb` in **Jupyter Notebook, Google Colab, or VS Code** and run the cells.
